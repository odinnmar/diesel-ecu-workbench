SOI / EOI calculator

Compare stock and tuned injection timing at matching operating points. Enter the duration and SOI that correspond to each file’s own IQ value, then press Calculate.

Important: match each SOI to its own fuel quantity.
Enter the stock duration and stock SOI for the same stock IQ point, then the tuned duration and tuned SOI for the same tuned IQ point. Select the SOI sign convention below to match how your map values are displayed. Example: stock maps at 60 mg/stroke must not be compared with a tuned SOI at 85 mg/stroke while reusing the old duration. Read/interpolate each value at the same RPM and its corresponding IQ. Confirm duration units and scaling first.
EOI formula: EOI relative to TDC = duration in crank degrees − SOI in positive BTDC convention. If your SOI values are signed angles (BTDC negative), choose Signed and the tool converts the sign. This is only valid if the entered duration is the effective injection duration in the selected units.
How to read the result: EOI means when injection ends relative to top dead centre (TDC). A positive result is after TDC. “SOI for target EOI” works backwards from the target you enter. The target-SOI result uses the tuned duration converted to crank degrees first. This is a calculation, not a recommendation for a safe target.

Continue a row of map values

Enter the last two values from a row or column. The calculator repeats their difference to estimate the next values.

Example: previous = 41 and last = 40. The difference is −1, so the next value is 39, then 38. Use this only as a mathematical estimate; real map curves often do not continue in a straight line.

Enter values from a diagnostic log at the same RPM. Requested means what the ECU asks for; actual means what the sensors report. Add one row for each RPM point.

Example: if requested boost is 2400 mbar and actual boost is 2300 mbar, enter 2400 and 2300 in the same row. The error is −100 mbar. Use absolute pressure values, not gauge boost.

Convert a value between units

Enter a number, choose its current unit, then choose the unit you want. Only compatible unit types can be converted.

Fuel volume ↔ mass uses the diesel density entered above (default 0.835 mg/mm³, an approximation). Actual density varies with fuel and temperature. This is a volume/mass conversion, not an ECU-specific injection-quantity calibration.

Duration time to crank degrees

Use this only if your duration map is in microseconds or milliseconds. Enter the engine RPM at the operating point.

Formula: crank degrees = duration in seconds × RPM × 360 ÷ 60. If the duration map is already in crank degrees, do not convert it again.

Torque to power calculator

Enter torque in Nm and engine RPM. It calculates the theoretical power at that torque and RPM.

Absolute boost to gauge boost

If your logger says 2400 mbar absolute and ambient pressure is 1000 mbar, gauge boost is 1400 mbar.

Ambient pressure changes with weather and altitude. This conversion is arithmetic, not a turbo capability check.

Session status

This tool runs locally in your browser. Nothing is uploaded to a server.

1. Fuel quantity estimate

A rough comparison tool. It does not know your injector flow curve, nozzle size, actual injection pressure at the nozzle, or ECU duration conversion.

How to use: enter a known baseline IQ and its matching duration/rail pressure, then enter the new duration and rail pressure. The tool compares estimated delivery using a simplified duration × √pressure relationship.
This simplified model is only a rough comparison, not a calibrated injector model. Real delivery is not perfectly linear, and rail pressure does not by itself establish injected quantity. Verify with correct injector data and logs.

2. Map smoothness checker

Paste one map grid. The tool highlights large jumps between adjacent cells for review; it does not automatically decide that a cell is wrong.

Use a threshold that makes sense for this map's units and scale.

Paste a numeric grid to begin.

3. Map relationship checker

Compare values at the same operating point. Enter values from maps with matching RPM/load axes and compatible units.

Example: if Driver Wish requests 75 mg/stroke and the active IQ limiter permits 68 mg/stroke at the same point, the smaller limit may constrain the request. Real ECU strategies can include other limiters and conversions.
Only compare values that have been converted to the same quantity and units.

4. Guided input mode

Plain-language reminders for common fields. Choose a calculator and see what each input means.

5. Calibration change report

Record what changed and why. Export a CSV report you can keep with the project. This report does not read or validate ECU binaries.
