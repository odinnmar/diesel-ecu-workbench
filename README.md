# Diesel ECU Workbench

Offline-first Windows desktop workbench for diesel ECU calibration calculations, with an integrated Diesel HP Estimator and optional automatic updates.

## What is included

- Existing SOI/EOI, map maths, screenshot map extender, map compare, log analysis, units/fuel, project checks and tuning helpers.
- Integrated Diesel HP Estimator in its own workspace tab, packaged locally so it works offline.
- Automatic update checks in installed Windows builds. Updates download in the background when internet is available; the app remains usable offline and prompts when an update is ready to install.
- Windows NSIS setup installer with desktop and Start Menu shortcuts.

## End users

Install the `Diesel-ECU-Workbench-Setup-1.2.0.exe` from the GitHub Releases page. Keep using the app normally. When a release is published, the app checks for it automatically and offers to restart once the update has downloaded. No update is required to use the app offline.

## Publishing a new version

1. Update `version` in `package.json` (for example `1.2.1`).
2. Commit and push to `main`/`master`. This creates a CI build artifact for testing.
3. Create and push a matching version tag, e.g. `v1.2.1`. The tag workflow publishes a GitHub Release and the Windows installer.
4. The `odinnmar/diesel-ecu-workbench` repository must allow Actions to write releases. The workflow uses its built-in `GITHUB_TOKEN`; no personal token is required.

**Important:** publish a new version with a version number higher than the installed version. Do not delete older releases while users may still be on them. Auto-update metadata and installer are generated by electron-builder.

## Build locally (maintainer only)

Requires Node.js 22+ on the build machine. End users do not need Node.js.

```bash
npm install
npm start
npm run dist:win
```

The installer is written to `release/`. CI builds it on Windows using GitHub Actions.

## Limitations and safety

- Auto-updates require internet access and a published GitHub Release; offline use continues with the last installed version.
- The update is offered after download and installs when the user chooses restart.
- This tool provides engineering estimates, not a substitute for ECU-specific documentation, logs, or dyno validation. Keep untouched backups of original ECU files.


## Visible updater status
The installed Windows app shows its version and a **Check for updates** button in the top bar. Update checks use `electron-updater` and the GitHub Releases provider configured in `package.json`. Release assets and metadata must be published successfully for updates to work. Branch builds create artifacts only; pushing a version tag such as `v1.2.1` publishes a release. The first upgrade from older installers remains a manual install.

## Workspace color accents
